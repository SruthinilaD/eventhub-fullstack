# EventHub

EventHub is a full-stack event discovery and ticket-booking platform.

Users can browse events, view available seats, select seats, and book tickets. Organizers can create and manage events, while administrators can manage the platform.

## User Roles

### Customer
- Register and login
- Browse and search events
- Filter events
- View event details
- Select seats
- Book tickets
- View booking history
- Cancel eligible bookings
- Receive notifications

### Organizer
- Create events
- Edit events
- Publish or cancel events
- Manage venues and seats
- View bookings
- View revenue and statistics

### Admin
- Manage users
- Manage organizers
- Manage events
- Manage bookings
- View platform statistics
